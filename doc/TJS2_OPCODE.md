# 🧩 TJS2 虚拟机 (TJS2 Virtual Machine)

TJS2 VM 是一种基于寄存器（Register-based）的解释型虚拟机。
脚本在执行前会被编译为针对 **TJS2 VM** 的二进制指令序列。
当发生异常、调试或转储时，解释器可以输出指令的反汇编形式。
本节对虚拟机执行模型、寄存器语义和主要指令集进行详细说明。

---

## 1️⃣ 执行模型概述

* 每个函数（或属性 getter/setter、脚本单元）在运行时对应一个独立的 **执行上下文（Execution Context）**。
* 每个上下文包含：

    * **寄存器文件 (Register File)**
      存储局部变量、参数和临时值；
    * **指令空间 (Code Segment)**
      函数体编译后的指令数组；
    * **常量区 (Constant Pool)**
      存储字符串常量、数字常量、属性名；
    * **标志寄存器 (Flag Register)**
      保存最近一次比较结果（真 / 假）；
    * **指令指针 (IP)**
      当前执行的指令索引，初始为 0。

VM 没有硬件堆栈，所有局部值都放在寄存器中。
函数调用使用新的上下文（新的寄存器空间），参数与返回值在寄存器间传递。

---

## 2️⃣ 寄存器模型

寄存器在助记符中用 `%数字` 表示，数字可以为负数。
寄存器数量理论上无限制。

| 寄存器编号           | 含义                                              |
|-----------------|-------------------------------------------------|
| `%0`            | 永远为 `void`（只读）                                  |
| `%-1`           | 当前函数的 `this` 对象                                 |
| `%-2`           | `this proxy`，属性解析时先查 `this`，再查 global（全局单元中不存在） |
| `%-3`, `%-4`, … | 函数参数（从左到右递减）                                    |
| 其他寄存器           | 局部变量或临时值；执行开始时未定义                               |

> 💡 实现建议：解释器可使用 `std::vector<Value>` 存储寄存器，
> `%n` 映射为 `registers[n + offset]`，负号寄存器可单独索引或预先映射。

---

## 3️⃣ 常量区 (Constant Pool)

* 常量区为只读数组，用于保存：

    * 字符串、数值常量；
    * 属性名（用于对象成员访问）。
* 助记符中用 `*数字` 表示常量索引。
* 示例：

  ```
  const %1, *3   ; %1 = 常量区[3]
  ```

---

## 4️⃣ 标志寄存器 (Flag Register)

* VM 仅有一个标志寄存器（布尔值）。
* 比较指令 (`ceq`, `clt`, `cgt` 等) 会修改此标志；
* 条件跳转指令 (`jf`, `jnf`) 读取此标志；
* `nf` 指令反转标志位状态；
* 标志寄存器不存储于通用寄存器文件中。

---

## 5️⃣ 操作数与成员访问形式

在助记符中，对象成员引用有两种主要形式：

| 形式           | 含义                    | 访问类型     | 助记符后缀      |
|--------------|-----------------------|----------|------------|
| `%obj.*name` | 直接访问对象的常量成员（编译期确定的名字） | Direct   | `d` / `pd` |
| `%obj.%name` | 间接访问对象成员（成员名由寄存器值决定）  | Indirect | `i` / `pi` |

带 `p` 后缀的指令会调用属性处理器（类似单目 `*` 操作），触发 getter/setter：

| 后缀  | 意义                             |
|-----|--------------------------------|
| `d` | 直接属性访问（常量名）                    |
| `i` | 间接属性访问（动态名）                    |
| `p` | 调用属性处理器（访问时触发 getter / setter） |

示例：

```tjs
gpd %2, %1.*foo   ; %2 = %1.foo
gpi %3, %1.%bar   ; %3 = %1[bar]
spdp %1, %0.*baz  ; 调用 setter 设置 foo 属性
```

## 6️⃣ 指令分组

### 6.1 基础操作

| 指令      | 功能            |
|---------|---------------|
| `nop`   | 无操作           |
| `const` | 拷贝常量区的值到寄存器   |
| `cp`    | 拷贝寄存器值        |
| `cl`    | 清空寄存器         |
| `ccl`   | 清空寄存器范围（连续区间） |

---

### 6.2 比较与条件跳转

| 指令              | 功能                 |
|-----------------|--------------------|
| `ceq`, `cdeq`   | 比较相等 / 严格相等（修改标志位） |
| `clt`, `cgt`    | 比较大小（修改标志位）        |
| `tt`, `tf`      | 测试寄存器为真/假，修改标志位    |
| `setf`, `setnf` | 根据标志位设置寄存器值        |
| `lnot`, `nf`    | 逻辑取反 / 反转标志位       |
| `jf`, `jnf`     | 根据标志位条件跳转          |

---

### 6.3 算术运算

| 指令                                        | 功能        |
|-------------------------------------------|-----------|
| `add`, `sub`, `mul`, `div`, `idiv`, `mod` | 算术计算      |
| `inc`, `dec`, `chs`                       | 自增、自减、取负  |
| `num`, `int`, `real`, `string`, `octet`   | 类型转换      |
| `asc`, `chr`                              | 数值 ↔ 字符转换 |

---

### 6.4 位运算

| 指令                    | 功能               |
|-----------------------|------------------|
| `bnot`                | 按位取反             |
| `band`, `bor`, `bxor` | 按位与 / 或 / 异或     |
| `sal`, `sar`, `sr`    | 左移 / 算术右移 / 逻辑右移 |

---

### 6.5 对象与属性访问

| 指令                    | 功能               |
|-----------------------|------------------|
| `gpd`, `gpds`         | 获取直接属性值          |
| `gpi`, `gpis`         | 获取间接属性值          |
| `spd`, `spde`, `spds` | 设置直接属性           |
| `spi`, `spie`, `spis` | 设置间接属性           |
| `getp`, `setp`        | 调用 getter/setter |
| `deld`, `deli`        | 删除对象成员           |
| `chgthis`             | 修改当前 this 指针     |
| `global`              | 取全局对象            |

---

### 6.6 函数与调用

| 指令                       | 功能              |
|--------------------------|-----------------|
| `call`, `calld`, `calli` | 调用函数            |
| `srv`                    | 设置函数返回值（存储于寄存器） |
| `ret`                    | 返回调用方           |

---

### 6.7 异常处理与调试

| 指令         | 功能             |
|------------|----------------|
| `entry`    | 进入异常保护区（try 块） |
| `extry`    | 退出异常保护区        |
| `throw`    | 抛出异常对象         |
| `debugger` | 触发调试器中断        |

---

## 7️⃣ 控制流与异常语义

* `entry` 与 `extry` 指令用于描述可捕获的异常范围；
* 解释器维护一个异常栈（Try Stack），保存：

    * 起始 IP、结束 IP；
    * 异常目标跳转位置；
    * 当前作用域信息；
* 执行 `throw` 时：

    * 搜索匹配的 `entry`；
    * 若找到，跳转到对应 `catch`；
    * 若未找到，向上抛出至上层函数；
* 执行 `debugger` 时：

    * 若调试器存在，暂停执行；
    * 否则忽略（无操作）。

---

## 8️⃣ 执行循环（伪代码）

```cpp
while (true) {
    auto& op = code[ip++];

    switch (op.opcode) {
        case OP_CONST:
            regs[op.dst] = constPool[op.arg];
            break;

        case OP_ADD:
            regs[op.dst] = regs[op.a] + regs[op.b];
            break;

        case OP_JF:
            if (flag) ip = op.target;
            break;

        case OP_RET:
            return regs[op.src];
    }
}
```
