# 表达式和运算符

> 原文：TJS2 リファレンス「式と演算子」章（[镜像 expr_and_op.html](https://a-rabin.github.io/krkr2doc-en/tjs2doc/contents/expr_and_op.html)），本文在其原译基础上整理补全。

## 表达式

表达式是运算符和操作数(operand)的集合，或者是常量。

通常用以下格式书写。

```text
表达式;
```

像这样在表达式的后面加上分号(;)的话，该表达式会被当场求值( = 执行 )，而产生的结果会被丢弃。

### 例

```text
a = b;
// 由于 = 运算符的作用，b变量 的值被代入到 a变量 中

func();
// 由于 ( ) 运算符的作用，func 作为函数被调用，函数的返回值被舍弃

1 + 3;
// 由于 + 运算符的作用，1 和 3 被求和，其结果被舍弃(实际上
// 因为这个表达式没有意义，它不会被执行)
```

---

## 真(true) 和 假(false)

有些运算符用于对真和假 (逻辑值) 进行处理。运算结果为 0 是代表 假(false) ，非0 是代表 真(true) 。

对字符串判断真假的时候，空字符串为 假、字符串非空的时候会被尝试转换为数值。如果转换成功就以转换结果的数值来判断真假，转换不成功则认定为 假。

---

## 运算符

下面以**优先级由低到高**的顺序对各个运算符进行说明。

---

## if 运算符

条件运算符 `if` 会对其右侧的表达式求值，如果结果为 真 ，就会对左侧的表达式求值。

### 例

```text
a=b if b!=0; // 如果 b 不为 0 则将 b 的值代入 a
```

该运算符并不返回运算结果。

---

## 顺序运算符

顺序运算符 `,` (逗号) 会先对左侧的表达式求值，然后对右侧的表达式求值。除此以外什么都不做。右侧的表达式的结果会作为该运算符的执行结果。连续出现多个逗号的时候，会从左侧开始依次求值。

### 例

```text
c = (a=1, b=2); // 对 a=1, b=2 这两个表达式进行求值，后面的表达式的结果 2 会被带入 变量 c 中
a=1, b=2, c=3; // 按照 a=1, b=2, c=3 的顺序依次求值
```

---

## 赋值运算符

下面的这些就是赋值运算符。

```text
=  <->  &=  |=  ^=  -=  +=  %=  /=  \=  *=  ||=  &&=  >>=  <<=  >>>=
```

### = 运算符

`=` 运算符是单纯的赋值运算符，其作用是，先对右侧的表达式求值，然后将求得的结果代入左边的变量。以右侧的表达式的值作为该运算符的运算结果。

#### 例

```text
a = 0;  // 将 0 代入 变量 a
a = b = c = 0; // 将 0 依次代入变量 c , b, a
```

### <-> 运算符

`<->` 运算符用来进行值的交换。首先对左侧的表达式求值，然后对右侧的表达式求值。在那之后，将右侧表达式的值代入左侧的变量，左侧表达式的值代入右侧的变量。该运算符不返回结果。

就目前来讲，为了对运算符左侧和右侧的表达式分别求值和代入，两侧的表达式发生了重复求值的现象。以后这个方法可能会改变，所以请不要设计利用这一特征的算法。

除此之外的运算符都属于 `运算符=` 的形式，`A 运算符= B` 的写法相当于 `A = A 运算符 B` 。`A 运算符 B` 的结果就会作该运算符(运算符=)的结果。

---

## 条件运算符

条件运算符 `? :` 是一个三目运算符。写成 `A ? B : C` 的形式的话，会先对 A表达式 求值。结果为真的时候会对 B表达式 求值，忽略 C表达式。结果为假的时候会对 C表达式 求值，忽略 B表达式。B表达式 和 C表达式 中被求值的那个表达式的值会作为该运算符的结果。

条件运算符可以作为左值使用。

### 例

```text
a = b==0 ? c : b; // 如果 b 等于 0 那么 将 c 代入 a ，如果 b 不等于 0 则将 b 代入 a
b==0 ? (a=c) : (a=b); // 和上面的表达式具有相同的意义
(a ? b : c ) = d; // 如果 a 为真，则将 d 代入 b ，如果a为假的话，则将 d 代入 c
```

---

## 逻辑 或(OR) 运算符

逻辑或运算符 `||` 会先对左侧的表达式求值，若结果为真，则忽略右侧的表达式，以“真”作为该运算符的结果。如果左侧表达式的结果为假，则对右侧的表达式进行求值，其结果(真或者假)作为该运算符的结果。

---

## 逻辑 与(AND) 运算符

逻辑与运算符 `&&` 会先对左侧的表达式求值，如果结果为假，则忽略右侧的表达式，以“假”作为该运算符的结果。如果左侧的表达式的结果为真，则对右侧的表达式进行求值，其结果(真或者假)作为该运算符的结果。

---

## 按位 或(OR) 运算符

按位或运算符 `|` 用于对每个 字位(bit) 进行逻辑或运算。先对左右两侧的表达式分别进行求值，将两个结果作为整数，按位逐个进行或运算，其结果作为该运算符的结果。

---

## 按位 异或(XOR) 运算符

按位异或运算符 `^` 用于对每个 字位(bit) 进行逻辑异或运算。先对左右两侧的表达式分别进行求值，将两个结果作为整数，按位逐个进行异或运算，其结果作为该运算符的结果。

---

## 按位 与(AND) 运算符

按位与运算符 `&` 用于对每个 字位(bit) 进行逻辑与运算。先对左右两侧的表达式分别进行求值，将两个结果作为整数，按位逐个进行与运算，其结果作为该运算符的结果。

---

## 相等判断运算符

`==`  `!=`  `===`  `!==` 都属于相等判断运算符这一类。

### == 运算符

`==` 运算符会先对左侧表达式求值，然后对右侧表达式求值。如果两个表达式的结果一致则该运算符的结果为真，不一致则该运算符的结果为假。两侧表达式的结果的数据类型如果不相同，则会进行适当的转换后再进行比较。例如，`-1 == '-1'` 结果为真。

### != 运算符

`!=` 运算符就是把 `==` 运算符的结果进行真假互换。

### === 运算符

`===` 运算符被称为 类型识别比较运算符，它与 `==` 运算符类似，区别在于它不会进行数据类型自动转换，数据类型不同即被判断为假。

### !== 运算符

`!==` 运算符就是把 `===` 运算符的结果进行真假互换。

---

## 比较运算符

`<`  `>`  `<=`  `>=` 都属于比较运算符这一类。

比较的双方都是字符串的时候，会按照宽字符的编码的顺序(通常是UNICODE)来进行比较。

---

## 按位 移位(shift) 运算符

`>>`  `<<`  `>>>` 都属于按位移位运算符这一类。

先对左侧表达式求值，再对右侧求值；左侧结果作为整数，按右侧结果的次数移位，移位结果作为运算符结果。

* `>>`：带符号右移（算术右移）
* `<<`：左移
* `>>>`：与 `>>` 相同，但把左侧结果作为**无符号**整数处理（TJS2 中唯一按无符号处理整数的地方）

---

## 加减运算符

`+`  `-` 分别为加法运算符和减法运算符。

`+` 先求值左侧再求值右侧：两边都是数值时按数值加法；**任意一边是字符串**时按字符串连接——结果是左侧结果后面接上右侧结果的字符串（数值会被转为字符串；对象类型能转成字符串则转换）。

`-` 先求值左侧再求值右侧，结果为左侧数值减去右侧数值。

---

## 乘除取余运算符

`%`  `/`  `\`  `*` 分别为取余、除法、整除和乘法运算符。都先求值左侧、再求值右侧：

* `%`：左侧除以右侧的**余数**，两边按**整数**处理
* `/`：左侧除以右侧的商，两边按**实数**处理
* `\`：同除法，但两边按**整数**处理（整除）
* `*`：左侧乘以右侧，两边按**实数**处理

---

## 一般的单目运算符

以下都是单目运算符（`instanceof` 除外）。

### ! 运算符（前置）

逻辑非。对右侧求值，真假的取反作为结果。

### ~ 运算符

按位取反。右侧求值结果作为整数，逐位取反（1→0、0→1）。

### -- / ++ 运算符（前置）

前置递减/递增。对右侧内容减 1 / 加 1，**运算后的值**作为运算符结果。

### new 运算符

使右侧的函数调用表达式不进行函数调用，而是**创建对象**（见 [Class.md](Class.md)）。

### invalidate 运算符

对右侧求值并**无效化**结果对象。右侧是 void、字符串、数值、octet 列时**什么都不做**；对象已被无效化时也什么都不做；指定 `null` 则**抛异常**。

### isvalid 运算符

对（左侧或右侧的）求值结果对象判断有效性：有效为 true、无效为 false。运算符写在操作数**前面或后面含义相同**（`isvalid obj` 与 `obj isvalid` 等价）。目标是 void、字符串、数值、octet 列时恒为真；指定 `null` 抛异常。

### delete 运算符

删除右侧所写**对象的成员或局部变量**。删除成功为 true、失败为 false。（注意：不是删除对象本身，见 [Class.md](Class.md) 对象销毁一节。）

### typeof 运算符

对右侧求值，按其类型返回字符串：void → `"void"`、整数 → `"Integer"`、实数 → `"Real"`、字符串 → `"String"`、对象 → `"Object"`、octet 列 → `"Octet"`。指定对象成员但成员不存在时返回 `"undefined"`。

### # 运算符

对右侧求值，其字符串形式**第一个字符的字符编码**作为结果。

### $ 运算符

对右侧求值，其结果作为字符编码，返回该编码表示的**一个字符**。

### + 运算符（单目）

对右侧求值。右侧是实数或整数则原样返回；否则尝试转换为数值：**转换失败不抛异常而是得到 0**。含小数点形式转为实数，否则整数；字符串前缀 `0x`、`0b`、`0` 分别按 16/2/8 进制解释。

### - 运算符（单目）

对右侧求值，其数值结果取反（正负翻转）。

### & 运算符（单目）

把右侧对对象成员的访问改为**不经属性处理器、直接访问属性对象本身**。如 `propobj = &obj.prop;` 不会触发 `obj.prop` 的 getter/setter，而是把成员属性 prop 的属性对象本身赋给 propobj。右侧不是属性访问时行为不定（见 [Property.md](Property.md)）。

### * 运算符（单目）

驱动右侧属性对象的**属性处理器**。右侧必须是一个属性对象：如 `*propobj = 1;` 调用 propobj 的 setter 写入 1。

### instanceof 运算符

先求值左侧，再求值右侧。右侧写**会成为类名字符串**的表达式；左侧结果是该类的实例则为 true，否则 false。

---

## 函数调用，括号类，后置的递增和递减等等

以下运算符优先级最高。

### ( ) 运算符

改变运算优先级；或进行函数调用。

### [ ] 运算符（间接成员选择）

`A[B]`：先求值 A，再求值 B。B 作为字符串（成员名）在 A 中查找成员，运算结果是对该成员的访问。作为**左值**使用时，若对象内不存在成员 B 则**新建**之。

### . 运算符（直接成员选择）

`A.B`：求值 A，在 A 中查找成员 B，运算结果是对该成员的访问。作为**左值**使用时，若不存在成员 B 则**新建**之。

`.` 的左侧被省略时：在 **with 语句外**引用全局对象的成员；在 **with 语句内**引用该 with 指定对象的成员（见 [ControlFlow.md](ControlFlow.md) with 一节）。

### ++ / -- 运算符（后置）

后置递增/递减。对左侧内容加 1 / 减 1，但**运算符的结果是加减之前**的左侧值。

### ! 运算符（后置，式求值运算符）

把左侧求值结果作为字符串，**当作表达式字符串解释并求值**，其结果作为运算符结果。表达式在该运算符使用位置的 **this 上下文**上执行。（即动态 eval。）

### incontextof 运算符

先求值左侧，再求值右侧。把左侧结果对象的**上下文部分**替换为右侧求值结果（见 [Class.md](Class.md) 闭包一节）。

### int / real / string 运算符

对右侧求值并分别转换为整数 / 实数 / 字符串类型。也可写成 C 风格的 `(int)` / `(real)` / `(string)`。
