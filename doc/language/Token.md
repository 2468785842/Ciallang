# 词法单元（Token）

> 原文：TJS2 リファレンス「トークン」章（[镜像 token.html](https://a-rabin.github.io/krkr2doc-en/tjs2doc/contents/token.html)）。
> 本目录各文档是原版 TJS2 语言规范的中文总结，行为基准以原文为准。

脚本在解释时先被分解为 **token（词法单元）** 序列。token 与下一个 token 的边界由 token 种类决定。

---

## 裸单词（bare word）

不经 `"` / `'` 引用、直接写在脚本中的特定字符序列，规则：

* 由字母（大小写）、`_`、数字、全角字符构成；**数字不能出现在开头**；
* 上述字符的连续序列整体作为一个裸单词。

```text
ampan        // OK
123a         // NG：数字开头
_asdf        // OK：下划线可开头
continue     // OK：这是保留字
全角文字     // OK：全角字符可用
```

裸单词进一步分为 **保留字** 和 **标识符** 两类。

---

## 保留字

保留字不是标识符。裸单词中除保留字外全部是标识符：

```text
break  continue  const  catch  class  case
debugger  default  delete  do  extends  export
enum  else  function  finally  false  for
global  getter  goto  incontextof  Infinity
invalidate  instanceof  isvalid  import  int  in
if  NaN  null  new  octet  protected  property
private  public  return  real  synchronized  switch
static  setter  string  super  typeof  throw
this  true  try  void  var  while  with
```

各自有构成语法的特殊含义，其中一些用作运算符。**并非所有保留字在当前版本中都被实际使用**（如 `export`、`goto`、`synchronized`、`enum`、`import`、`debugger` 等为预留）。

---

## 标识符

裸单词中非保留字的部分。用于自由命名的变量、函数、类名等。
标识符可以**包含**保留字子串，只要不与保留字完全相同（如 `function1` OK，`function` NG）。

---

## 符号

符号也是 token，采用**最长匹配**切分：

```text
>>>=  >>>  >>=  >>  >=  >  <<=  <=
<->  <<  <  ===  ==  =>  =  !==  !=  !
&&=  &&  &=  &  ||=
||  |=  |  ...  .  ++  +=  +  -=  --  -  *=
*  /=  /  \=  \  %=  %  ^=  ^  [  ]  (  )  ~
?  :  ,  ;  {  }  #  $
```

例如 `++` 会被切成一个 token 而不是 `+` `+`；需要两个 `+` 时必须在中间加空格等分隔。

---

## 数值字面量

以数字或 `.`（小数点）开头。支持的形式：

* **十进制**：直接书写；可用 `e`/`E` 指定以 10 为底的指数。
* **十六进制**：前缀 `0x`/`0X`。
* **二进制**：前缀 `0b`/`0B`。
* **八进制**：前缀 `0`。

```text
0  1  3.1  342.3          // 十进制
1e-3  3.4e10  9.3E-2      // 指数
0x1234  0Xff  0x3f33      // 十六进制
0b0100  0B0010100010100001 // 二进制
01234  033                // 八进制
```

十六/八/二进制**同样支持小数点形式和指数**，指数用 `p`（以 2 为底）：

```text
0b1.1    // 1 + 1/2 = 1.5
0x2.f    // 2 + 15/16 = 2.9375
0x1p8    // 1 × 2^8 = 256.0
```

只要是数值字面量的构成字符，就一直作为一个字面量处理。

---

## 字符串字面量

用 `""` 或 `''` 包围。两种引号等价；双引号内的单引号（反之亦然）**无需转义**。

`\` 具有特殊含义（转义）：

| 转义 | 含义 |
|---|---|
| `\\` | `\` 本身 |
| `\'` / `\"` | 单引号 / 双引号 |
| `\a` | BEL（响铃） |
| `\b` | BS（退格） |
| `\f` | FF（换页） |
| `\n` | LF（换行） |
| `\r` | CR（回车） |
| `\t` | HT（水平制表） |
| `\v` | VT（垂直制表） |
| `\xH` / `\XH` | H 为十六进制，表示该**字符编码**对应的一个字符 |

`\x` 后只要跟随十六进制字符（0-9、A-F、a-f）就会被纳入 H：宽字符 16bit 的环境最多识别 4 位，32bit 环境最多 8 位（Windows 为 16bit，Linux/Solaris 为 32bit）。

因此 `"\x22An Apple"` 的开头会被识别为 `\x22A`。要避免，可把字符串拆开**连续书写**——TJS 中连续的字符串字面量会被拼为一个字符串：

```text
"\x22" "An Apple"
```

---

## @ 字符串字面量（嵌入式表达式展开）

字符串字面量前加 `@`，则字符串中 `&表达式;` 或 `${表达式}` 部分会被当作**表达式求值并展开**到该位置：

```text
@"1+2=&1+2;"          // → "1+2=3"
@"変数 f の内容は &f; です"
@"結果は &func(); です"
@"結果は ${func()} です"    // 同上
@"true \&\& false は &true && false;"  // \& \$ 不展开
```

* 不想展开 `&` / `$` 时，在其前加 `\`。
* 表达式可访问该字符串所在位置可见的变量（**包括局部变量**）。

---

## Octet（字节列）字面量

用 `<%` 和 `%>` 包围，内容为两位十六进制、以空白分隔：

```text
<% 00 01 02 03 %>
<% ff ff ff 00 04 0f ff 30 %>
```

---

## 正则表达式字面量

用 `/` 和 `/` 包围正则模式，后面可跟标志字符：

* `g`：全局匹配（匹配所有；缺省只匹配第一个）
* `i`：忽略英文字母大小写
* `l`：使用本地化排序规则

正则字面量作为 **RegExp 类的对象**处理。

```text
/[0-9]-[0-9]-[0-9]/
/^;\s*(.*?)\s*=(.*)$/
/start(.*?)end/gi
```
