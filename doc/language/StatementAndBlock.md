# 语句与块

> 原文：TJS2 リファレンス「ステートメントとブロック」章（[镜像 statement_and_block.html](https://a-rabin.github.io/krkr2doc-en/tjs2doc/contents/statement_and_block.html)）。

语句（statement）与块（block）是 TJS2 语法的两大构成要素。

---

## 语句

语句以 `;`（分号）结束。有的是表达式后直接加分号，有的是 `if` 等控制语法后接分号：

```tjs
a++;
func1();
return a+b;
```

---

## 块

块把多个语句放在 `{ }` 中，从上到下依次执行：

```tjs
{
    a++;
    b++;
}
{
    var t=func1();
    func2(t);
    break;
}
```

* 块的**后面不需要分号**。
* **所有块都产生变量作用域**。

---

## 执行顺序

写在函数、类、属性**之外**的语句随脚本执行而立即执行；函数/类/属性**内部**的语句在被调用前不执行。

```tjs
var a;          // 立即执行
function test()
{
    a+=10;      // 调用前不执行
}
a+=30;          // 立即执行
```

更准确地说：**类、函数、属性的定义在脚本执行时最先被注册**，然后其余脚本要素才从头开始执行。因此函数/类/属性在**同一脚本块内可以后向引用**：

```tjs
test();  // 引用了定义在后面的函数——同脚本块内 OK
function test()
{
    inform("yah!");
}
```

* 跨脚本块的函数调用：在尝试调用的时刻目标函数已加载则可行。
* **变量的声明按加载顺序处理，不能后向引用**。

---

## 全局对象

全局对象是特殊的对象，持有在全局位置（所有块/类/函数之外）声明的变量、函数、属性等作为成员，用 `global` 关键字访问（见 [Factor.md](Factor.md)）。
