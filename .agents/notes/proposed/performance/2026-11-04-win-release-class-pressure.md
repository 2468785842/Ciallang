# Windows Release 类压力回退归因

Status: proposed

## 问题

结构化异常栈/getter 隔离批次后，Windows Release 的类压力用例（2 万次实例化）
出现约 +8% 回退，同机两次测量方向一致，尚未归因。

## 已知事实与证据

- 测量见[性能记录](../../../../doc/performance.md#2026-11-01-结构化异常栈与-getter-异常隔离)；
  该批次涉及异常表与调用帧路径，类实例化压力路径可能受异常表布局或帧构建影响。

## 建议下一步

Windows Release 下对照批次前后：剖析热点、检查异常表尺寸与查找路径、
核对实例化路径是否新增每对象工作；区分常量开销与路径退化。

## 完成条件

归因并处理（消除退化或记录接受理由），结论同步性能记录与本 note 状态。

## 风险或备选方案

异常栈隔离是行为正确性改动，回退处理不得回退可观察的异常语义；
测量需注明 MSVC 版本与机器环境。
